# niti improvement research — merged plan (Rounds 1–3)

**Date:** 2026-10-11 · **niti:** 0.4.7, `main` @ 53df9ba

[Round 2 — Exa](./2026-10-round2-exa.md) (33 searches, 12 full reads) ·
[Round 3 — Exa, deeper](./2026-10-round3-exa-deep.md) (33 searches). Evidence and sources are in

**Scope:** almost all of this touches `src/`, the `niti-core` engine that **both** the CLI and the

**Rule for every item:** measure dollars per solved task, priced with cache rates, over paired
repeated runs. Single runs swing 2–6 points (R2), and token counts alone mislead (R1).

## The plan

### Tier 0 — correctness (small, do first)

1. **Send reasoning back on the OpenAI-compatible path.** Capture `reasoning_content` /
   `reasoning_details` into `raw` and replay them (`openai.ts:56-80`). Also fold mid-task
   harness turns (verification failure, stall nudge, inbox, notes, todo) into the preceding `tool`
   message, so DeepSeek-style templates don't treat each one as a new user message and drop the
   reasoning. Evidence: DeepSeek docs (400 without it), Kimi docs, MiniMax ablation (BrowseComp 44.0
   vs 31.4, τ² 87 vs 64), DeepSeek V3.2 retention rule. Affects DeepSeek, Kimi, GLM, MiniMax, Qwen,
   OpenRouter.
2. **Refresh the OpenAI catalog.** `catalog.ts:112-116` lists only gpt-4o / gpt-4o-mini / o3-mini /
   o1.

### Tier 1 — cheap, well supported (small)

3. **Eval:** cache-priced $ per solved task, failed runs in the numerator, paired repeats with
   confidence intervals, turns per solved task, critical steps for team runs. (R1 #1, R2 #01/N2,
   R3-1)
4. **Cache lifetimes:** Anthropic `ttl: "1h"` on the system/tools breakpoint (`anthropic.ts:5`).
   OpenAI `prompt_cache_retention: "24h"` where the model supports it. Plan explicit breakpoints for
   GPT-5.6+. Then audit per-turn injected text. (R1 #5, R2 #02, R3-2)
5. **Repo map on vs off**, judged on $ per solved task. If it doesn't pay, keep only the `repo_map`
   tool. (R2 N1, R3-9)
6. **Planner:** keep a dependent chain on one agent; split only independent work on separate files.
   Log planned vs actual hand-offs and watch for serial collapse / spurious parallelism. (R1 #3,
   R2 #03/N8, R3-6)
7. **Review policy:** a separate reviewer told to be skeptical, at least as strong as the author or
   the same model in a fresh session. On work that already passed verification it comments rather
   than rewrites. (R1 #4, R2 #06, R3 Anthropic harness post)
8. **Test/build log filter:** for known runners keep failures, `file:line`, error text and the
   summary; write the full log under `.niti/` and print its path. Never for `read_file` / `grep`.
   (R1 avoid → R3-4)
9. **Budget line:** "turn N of 30, $X spent" inside the todo block that is already re-sent. (R3 N11)
10. **Taint across delegation:** a task created by a lead that has read untrusted content keeps the
    stricter egress approval on the teammate. (R1 §3, R2 #11, R3-10)
11. **Steer batching of independent reads** (per family, in `steering.ts`). Track turns in the eval.
    (R2 N6, R3 N15)

### Tier 2 — bigger, strong evidence (medium)

12. **Scout, then fix.** A cheap teammate localizes the bug and writes a reproduction test that
    verification confirms fails; the fixer works from that handoff. Escalate to the strong model on
    early signals (stall, failed repro), not up front. Evidence: Scrouting matched the best model at
    ~1/5 cost per solve, and the handoff carried the result; SWE-Router; ReProAgent +10 / +13 solved.
    (R1 #7, R2 #07, R3 N10)
13. **Several attempts, best one wins.** First, sequential retry on another model that stops at the
    first verified pass. Then opt-in parallel attempts in worktrees: filter by verification, then a
    judge, with shortest / least-deliberating trajectory as the tie-break. (R1 #6, R2 #04, R3-11)
14. **Edit format per model tier.** Add a hashline mode (`read_file` already numbers lines) and turn
    it on for weaker / cheaper models through `steering.ts`. Keep `str_replace` for Claude / GPT.
    Never `apply_patch` for non-OpenAI models. (R1 #10, R2 #08, R3-7)
15. **Playbook from verified runs only.** Short itemised lessons, per project, visible and editable,
    never auto-loaded across projects, never written before the task. (R1 #8, R2 #05, R3-8)

### Tier 3 — later, each behind an eval run

16. Per-step reasoning effort, after checking it doesn't break the provider cache. (R2 N4, R3-11)
17. AgentDiet-style single-step reduction (cheap model, step two back, only if over 500 tokens). It
    overlaps masking, so it only stays if the eval shows a gain. (R3-3)
18. LSP references returning the line inline; structural navigation for blast-radius questions.
    (R2 N5, R3-9)
19. Provider-native MCP deferral, and later programmatic tool calling, for MCP-heavy users.
    (R1 #9, R2 #10, R3-5)
20. Lower absolute compaction threshold: a cost experiment, not a quality fix. (R1 #2, R2 #09, R3-3)
21. Harness settings per model tier (planning, tools vs bash). (R2 N3)

## Avoid (all rounds)

- Compressing **file reads** or grep output. It breaks edit anchors and triggers re-reads (R1, R3).
- Trained compressors that need a model niti doesn't ship (R1).
- Self-critique with no external signal; self-generated skills (R1, R3).
- More agents by default; splitting dependent work (R1, R2, R3).
- Client-side tool swapping mid-session, which breaks the cache (R2).
- Vendor-opaque compaction as the default path; niti's masking works on every provider (R3).
- Full CaMeL: −21.6 points of utility. The taint flag covers the multi-agent case (R3).
- Patch formats a model wasn't trained on (R3).
